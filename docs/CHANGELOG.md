# Memory Trail Changelog

## Version 1.4 — Official Release

Memory Trail 1.0 is the official Windows release baseline.

### Today & Activity Timeline
- Live chronological activity timeline with newest activity first.
- Captures foreground application and window context exposed by Windows.
- Supports browser pages/tabs, Outlook context, chat/conversation titles, files/documents, and other supported desktop activity.
- Live-capture state shows when Memory Trail is actively recording.
- Today at a Glance summarizes activities, apps used, active time, files/documents, and clipboard items.
- Top Apps Today uses real application icons and activity counts.
- Key Takeaways surfaces peak focus, top work type, and app-switching context.
- Recent Files & Documents provides fast access to current work.
- Full-history scrolling with recycling virtualization for performance.
- Back to Top control for long timelines.

### Ask Memory Trail
- Local natural-language search across captured history.
- Search by time, app, filename, subject, email, page, conversation, or nearby activity.
- Shortcut questions for common searches.
- Modern vector icon system for shortcuts and search states.
- Equal-height result rows with consistent timestamps and truncation.
- Real originating app icon for each search result.
- No artificial cap on matching search results.
- Back to Top support for large result sets.
- Search remains local to the PC.

### Favorites
- Save important timeline entries for quick access.
- Dedicated Favorites view and modern bookmark iconography.

### Clipboard History
- Optional clipboard capture for copied text and links.
- Dedicated Clipboard History view.
- Independent clipboard capture control.
- Modern clipboard iconography consistent across navigation and page headers.

### Insights
- Activity by App.
- Active-time and focus calculations.
- Activity patterns across the day.
- Peak-time and focus-streak metrics.
- Category/time distribution.
- Key takeaways generated from local timeline data.
- Modern analytics iconography and dashboard layout.

### Navigation & Visual Design
- Large primary sidebar navigation for Today, Ask Memory Trail, Favorites, Clipboard History, Insights, and Settings.
- Unified modern vector icon system across primary features.
- Matching feature icons reused across navigation and page headers.
- Arial Rounded MT-based visual language with clear fallbacks.
- ClearType/display text rendering, layout rounding, pixel snapping, and Per-Monitor-V2 DPI awareness.
- High-contrast, readable cards and controls.
- Polished onboarding tutorial and What's New experience.

### Privacy & Local Data
- Captured timeline history is processed and stored locally.
- No Memory Trail account is required.
- No cloud timeline sync is required.
- No analytics or advertising SDK is required for capture.
- No external data connector is required for core operation.
- Pause/resume capture controls.
- Application/process exclusions.
- Local data-folder access.
- JSON export.
- Clear last week, last month, or all history.
- Dedicated privacy policy and privacy-focused onboarding.

### Windows Integration
- System tray operation.
- Optional Start with Windows.
- Packaged startup support for Microsoft Store installs.
- Direct-download update checks with update/remind/skip behavior.
- Microsoft Store builds rely on Microsoft Store for updates.
- What's New is shown after upgrades.

### Outlook & Desktop Capture
- Classic and New Outlook capture support.
- Reading-pane subject/sender capture improvements.
- UI Automation filtering to avoid navigation/Copilot/Focused Inbox chrome where possible.
- Build fix for ambiguous UI Automation condition references.

### Distribution
- Self-contained Windows x64 ZIP release.
- Microsoft Store MSIX package.
- Partner Center identity verification in the Store build pipeline.
- Source-visible packaging and privacy implementation.

### Release Artifacts
- Direct download: `Memory-Trail-Windows-1.4-x64.zip`
- Microsoft Store package: `Memory-Trail-1.4-x64.msix`
