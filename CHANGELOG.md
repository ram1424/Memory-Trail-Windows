# Changelog

## 1.0.0

- Promoted the Windows edition to a stable 1.0 release.
- Added session-based active-time calculation using a five-minute inactivity boundary.
- Added dynamic Today filters that remain hidden until matching activity exists.
- Added double-click and Enter-key activity detail navigation from Ask Memory Trail results.
- Added installed-application discovery and a searchable privacy exclusion picker.
- Updated release packaging to `MemoryTrail.Windows.csproj` and a self-contained Windows x64 ZIP.
- Updated branding, documentation, privacy language, and release notes for Memory Trail.
